# 📊 Excel Data Analysis Portfolio

¡Bienvenido/a a mi portafolio de análisis de datos con Microsoft Excel!

Soy estudiante de Ingeniería de Sistemas y estoy desarrollando mis habilidades en análisis de datos mediante proyectos prácticos, aplicando herramientas y funciones de Excel para organizar, procesar, analizar y visualizar información.

Este repositorio reúne proyectos académicos y prácticos que reflejan mi aprendizaje y evolución en el análisis de datos.

## 🎯 Objetivo del repositorio

Construir un portafolio de proyectos que demuestre mis conocimientos en Excel, desde el manejo de datos y las funciones básicas hasta herramientas de análisis y visualización más avanzadas.

## 🛠️ Herramientas y tecnologías

* Microsoft Excel
* GitHub

## 📚 Organización del portafolio

Los proyectos están organizados según el nivel de aprendizaje:

### 🟢 01. Excel Básico

Proyectos enfocados en el manejo de datos, aplicación de funciones matemáticas, estadísticas y condicionales, elaboración de indicadores y análisis mediante tablas dinámicas y gráficos.

**Proyectos desarrollados:**

1. Análisis del Rendimiento Académico.
2. Control de Gastos Personales.
3. Análisis de Operaciones Bancarias.

📁 Carpeta: `Excel-Basico`

### 🟡 02. Excel Intermedio

Proyectos orientados al manejo de fechas, funciones lógicas, búsquedas, manipulación de texto, filtros avanzados y análisis de información mediante tablas dinámicas.

📁 Carpeta: `Excel-Intermedio`

**Estado:** En desarrollo.

### 🔵 03. Excel Avanzado

Próximamente incluiré proyectos enfocados en herramientas avanzadas de Excel, automatización y análisis de datos.

📁 Carpeta: `Excel-Avanzado`

**Estado:** Pendiente.

## 📈 Aprendizaje continuo

Este portafolio se encuentra en constante desarrollo. Cada proyecto representa una oportunidad para fortalecer mis habilidades técnicas, mejorar mi capacidad analítica y desarrollar soluciones utilizando herramientas de análisis de datos.

## 📌 Nota

Los datos utilizados en los proyectos son ficticios y tienen fines exclusivamente educativos.
